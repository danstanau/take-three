# Contributing

Thanks for helping improve Take Three. For substantial changes, open an issue
first to discuss the approach. Please don't include private recordings,
credentials, or personal information in issues or pull requests.

1. Fork the repository and create a branch.
2. Install Node.js 24, then run `npm ci` and `npm run dev`.
3. Make focused changes and run `npm test` and `npm run build`.
4. Open a pull request describing the change, how you checked it, and any
   browser or operating-system limitations.

Screen recording needs a browser and operating-system permissions, so changes
to capture should also be checked manually. See [SECURITY.md](SECURITY.md)
for reporting security vulnerabilities privately.
