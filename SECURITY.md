# Security

Take Three is an early prototype and has not been independently security
audited. Recordings are stored in the browser on the local device and, when
requested, uploaded directly to the chosen cloud provider. Do not rely on the
app as secure or backed-up storage for sensitive material. OAuth client IDs are
public configuration; never put client secrets into the browser application.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use
[GitHub's private vulnerability reporting](https://github.com/danstanau/take-three/security/advisories/new)
if it is enabled. Otherwise, contact the repository owner privately through
GitHub before sharing details. Include steps to reproduce and the affected
version, but do not include credentials or sensitive recordings.
